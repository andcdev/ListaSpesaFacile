Supprimer votre compte

Lista Spesa Facile — suppression du compte et de toutes les données

Saisissez l'e-mail que vous utilisez dans l'application : nous vous envoyons un code pour confirmer que la boîte vous appartient. Cela vaut aussi si vous vous connectez avec Google ou Amazon : dans ce cas, utilisez l'e-mail de ce compte.

Si est inscrite, vous recevrez bientôt un code à 6 chiffres (valable 30 minutes). Vérifiez aussi les spams.

Compte supprimé. Vos données ont été effacées. Vous pouvez désinstaller l'application : si vous la rouvrez, elle vous demandera de vous connecter.

Ce qui est supprimé

  • le compte : nom, e-mail, mot de passe, langue et photo de profil ;
  • le lien avec Google ou Amazon, si vous l'utilisiez pour vous connecter ;
  • les listes que vous avez créées, avec articles, photos, rappels et chat, y compris pour les personnes avec qui vous les partagiez ;
  • les partages : vous disparaissez des listes des autres auxquelles vous participiez ;
  • les messages et les photos que vous avez écrits dans les chats ;
  • les prix que vous aviez notés (« Mes prix ») ;
  • les notifications et les sessions de vos téléphones, qui sont déconnectés.

Ce qui reste

Les articles que vous avez ajoutés aux listes d'autres personnes restent dans leurs listes, sans votre nom. Les données techniques des accès (adresse IP, date et heure) s'effacent d'elles-mêmes, en principe sous 30 jours, comme expliqué dans la politique de confidentialité.

Vous ne recevez pas le code ? Écrivez à supporto@listaspesafacile.com depuis l'adresse avec laquelle vous êtes inscrit, avec l'objet « Supprimer le compte » : nous le supprimons sous 30 jours.

Vous voulez seulement retirer certaines données ? Dans l'application, vous pouvez supprimer une liste, ses articles et photos, vos messages, votre photo de profil et vos notifications, sans fermer le compte.
